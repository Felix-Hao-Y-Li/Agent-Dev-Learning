# Agent-Dev-Learning

记录我在 **Agent 开发求职准备**过程中的学习产出（笔记、代码、项目）。

## 学习路线

主线参照 GitHub 开源仓库 [AgentGuide](https://github.com/Felix-Hao-Y-Li/AgentGuide) 的 8 周学习路线图，但实际学习周期会比原计划更长——路线图的 8 个阶段是内容基准，不是时间硬约束。

| 阶段 | 主题 |
|---|---|
| Week 1 | LLM 应用基础 + Naive RAG |
| Week 2 | 进阶 RAG + 生产级向量数据库 |
| Week 3 | Agent 开发 + 工具调用 |
| Week 4 | 系统性能优化 |
| Week 5 | 监控可观测性与部署 |
| Week 6 | 多智能体系统 |
| Week 7-8 | 实战项目 + 面试准备 |

与主线**并行**推进一条数据结构与算法学习线：参考《代码随想录》，配合 LeetCode 刷题，解题笔记整理在 `dsa-notes/`。

详细的技术点、交付物和实时进度见 [CLAUDE.md](./CLAUDE.md)（本地文件，未提交到仓库）。
